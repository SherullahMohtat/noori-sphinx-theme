Architecture Overview
=====================

Unlike traditional themes that depend on large third-party framework layers, **Noori** is engineered directly on Sphinx's core HTML generator:

* **Clean Semantic HTML5**: Fully accessible layout, headers, and breadcrumbs.
* **Modern CSS Variables**: Native dark/light theming with zero layout shifting or flickering.
* **Pure Vanilla JavaScript**: Lightweight interactions (search trigger, copy snippet, mobile drawer, scrollspy).
